# LedgerGift — Telegram Mini App

Безопасный сервис сделок с Telegram-подарками, переписанный из обычного бота в **Telegram Mini App**
(красивый интерфейс внутри Telegram). Сохранён весь функционал
оригинала: сделки, балансы, профили, топ, языки, безопасность и админ-панель.

---

## ⚠️ Самое важное — прочти первым

Твой старый токен бота **был виден в загруженном файле** (`8892180302:AAG...`).
Если этот токен где-то ещё живой — **немедленно его отзови**:

1. Открой [@BotFather](https://t.me/BotFather)
2. `/mybots` → выбери бота → **API Token** → **Revoke current token**
3. Получи новый токен и вставь его в `.env` (поле `BOT_TOKEN`).

Никогда не выкладывай `.env` в публичный репозиторий.

## Структура проекта

```
ledgergift-miniapp/
├─ backend/            # сервер (FastAPI) + бот-запускатор
│  ├─ config.py        # читает .env, бренд, валюты, типы сделок
│  ├─ auth.py          # проверка подписи Telegram initData (HMAC)
│  ├─ db.py            # вся работа с базой (SQLite)
│  ├─ helpers.py       # форматирование, уровни продавца
│  ├─ main.py          # все API-маршруты + раздача фронта
│  └─ bot.py           # запускает бота, кнопку “Открыть”, скрывает /admin
├─ frontend/           # само Mini App (HTML/CSS/JS)
│  ├─ index.html
│  ├─ app.js           # вся логика экранов
│  ├─ i18n.js          # переводы (ru/en полные, zh/ar/ja/kk → en)
│  ├─ style.css        # тёмная премиальная тема (чёрный + циан)
│  └─ assets/          # логотип и иконки
├─ requirements.txt
├─ .env.example        # шаблон настроек
└─ README.md
```

## Шаг 1. Установка

```bash
cd ledgergift-miniapp
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 2. Настройка .env

```bash
cp .env.example .env
```

Заполни поля:
- `BOT_TOKEN` — НОВЫЙ токен от @BotFather;
- `BOT_USERNAME` — юзернейм бота без @ (напр. `LedgerGiftBot`);
- `WEBAPP_URL` — HTTPS-адрес, где будет висеть Mini App (см. шаг 5);
- `ADMIN_IDS` — твой Telegram ID (уже вписан `8706790108`), можно несколько через запятую;
- `SUPPORT_USERNAME` — менеджер поддержки (`LedgerManagerGift`);
- `PAYMENT_URL` — куда ведёт кнопка пополнения.

> Как узнать свой ID: напиши [@userinfobot](https://t.me/userinfobot).

## Шаг 3. Запуск сервера (API + фронт)

```bash
cd backend
uvicorn main:app --host 127.0.0.1 --port 8080
```

Сервер раздаёт и API, и саму страницу Mini App из папки `frontend/`.

## Шаг 4. Запуск бота (отдельный процесс)

```bash
cd backend
python bot.py
```

Бот по команде `/start` покажет кнопку “Открыть LedgerGift”.
Команда `/admin` видна **только** тем, чьи ID есть в `ADMIN_IDS`
(через персональное меню команд Telegram). У обычных пользователей её нет,
а кнопка “Админ” в интерфейсе у них не показывается. Кроме того, сервер
всё равно отдаёт 403 на админ-запросы от не-админов — обойти нельзя.

## Шаг 5. Публичный HTTPS-адрес

Telegram требует HTTPS. Варианты:
- выложить на свой сервер/VPS с доменом и SSL (напр. Nginx + Let’s Encrypt);
- или любой хостинг, который даёт HTTPS.

Полученный адрес (напр. `https://ledgergift.example.com`) впиши в `WEBAPP_URL`.

## Шаг 6. Привязка Mini App в @BotFather

1. [@BotFather](https://t.me/BotFather) → `/mybots` → твой бот → **Bot Settings** → **Menu Button** → **Configure menu button** → вставь `WEBAPP_URL`.
2. Для deep-ссылок на сделки: `/newapp` → выбери бота, задай короткое имя приложения (short name) — оно должно совпадать с `MINIAPP_SHORT_NAME` в `config.py` (по умолчанию `app`).

Ссылка на сделку выглядит так:
`https://t.me/<BOT_USERNAME>/<short_name>?startapp=deal_LGXXXXXX`

## Админ-панель

Внутри Mini App у админа есть раздел “Админ”:
- Пополнить баланс пользователя (любая валюта);
- Проверить пользователя (профиль + балансы + логи);
- Найти сделку по тегу;
- Накрутить статистику (ордеры/рейтинг/оборот);
- Сменить ссылку пополнения;
- Мои логи;
- Добавить админа (только владелец из `ADMIN_IDS`/`OWNER_ID`).

## Главные отличия от старого бота
- Бренд везде **LedgerGift** + новый логотип (щит-подарок на чёрном).
- Интерфейс — полноценное Mini App (экраны, анимации, нижняя панель), а не кнопки в чате.
- Префикс сделок — `LG`.
- Авторизация через подпись Telegram `initData` — ID пользователя нельзя подделать.

## Безопасность
- Все запросы проверяют подпись Telegram (HMAC-SHA256 по токену бота).
- Админ-маршруты защищены на сервере (403 для не-админов).
- Сервер слушает только `127.0.0.1` — наружу выставляй через reverse-proxy с HTTPS.
